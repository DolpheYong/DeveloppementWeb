CHAPITRE 2

Introduction au HTML

Découvrez le rôle du HTML, son fonctionnement, les principaux outils utilisés pour écrire du code et les notions fondamentales des balises HTML.

01

Qu'est-ce que le HTML ?

HTML signifie HyperText Markup Language. Il correspond au langage de balisage hypertexte qui constitue la base des pages web.

🌐

HTML n'est pas un langage de programmation

HTML est un langage de balisage standard. Il permet de définir la structure et le contenu des pages web.

Il utilise des balises pour indiquer au navigateur la nature des différents éléments présents dans une page.

À retenir : HTML définit principalement la structure et le contenu d'une page web. Il ne s'agit pas d'un langage de programmation.
🧱

Que permet HTML ?

Les balises HTML permettent de décrire les différents éléments d'une page.

Structure

HTML permet de construire la structure générale d'une page web.

Contenu

HTML permet d'intégrer différents types de contenus dans une page.

Sémantique

Les éléments HTML donnent un sens au contenu, ce qui facilite notamment l'accessibilité et l'indexation.

02

HTML, CSS et JavaScript

HTML, CSS et JavaScript sont trois technologies complémentaires utilisées dans le développement web.

HTML

Structure et contenu de la page.

  • Structure
  • Texte
  • Liens
  • Images
  • Formulaires

CSS

Style et mise en forme.

  • Couleurs
  • Polices
  • Marges
  • Mise en page

JavaScript

Interactivité, animations et dynamisme.

  • Interactions
  • Animations
  • Dynamisme
Principe fondamental : la séparation du contenu et de la présentation permet de modifier l'apparence d'une page grâce au CSS sans modifier son contenu HTML.

04

Les balises HTML

Une balise est une suite de caractères écrite entre les chevrons < et >.

🏷️

Le rôle des balises

Une balise indique au navigateur la nature du contenu qu'elle englobe et permet de déterminer comment cet élément doit être reconnu et affiché.

Exemples d'éléments HTML : paragraphes, listes, en-têtes, liens, images, lecteurs multimédias et formulaires.
💻

Exemple de balise HTML

Une balise permet de préciser la nature d'un élément de la page. 

<p>Bonjour Génie Logic !</p>

Ici, la balise <p> indique un paragraphe.

✓

À retenir

HTML est un langage de balisage qui permet de définir la structure et le contenu d'une page web. Il fonctionne avec CSS pour la présentation et JavaScript pour l'interactivité.
