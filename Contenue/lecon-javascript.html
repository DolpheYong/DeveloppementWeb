LEÇON JAVASCRIPT

Les bases du langage

JavaScript rend les pages web interactives : cette leçon présente ses concepts de base, des variables aux fonctions, puis les objets intégrés les plus utilisés.

Oct 24, 2026 · @Dolphe

🎯

Objectifs

À la fin de cette leçon, l'apprenant sera capable de :

  • définir JavaScript et citer ses principaux usages ;
  • déclarer des variables avec var, let et const et comprendre leur portée ;
  • manipuler les types de données, les littéraux et les opérateurs ;
  • écrire des conditions, des boucles et des fonctions ;
  • exécuter du code dans le navigateur ou avec Node.js ;
  • utiliser les objets Date, String, Math et document.
01

Introduction

JavaScript est un langage de programmation de haut niveau, interprété et orienté objet. Il a été créé pour les navigateurs web, afin de rendre les pages interactives et dynamiques, mais il s'utilise aujourd'hui dans d'autres contextes.

⚡

À quoi sert JavaScript ?

  • Interactivité web : formulaires interactifs, animations, menus déroulants, mise à jour du contenu en temps réel sans recharger la page ;
  • Manipulation du DOM : modifier, ajouter ou supprimer dynamiquement les éléments de la page ;
  • Validation de formulaires : vérifier les données saisies avant leur envoi au serveur ;
  • Gestion d'événements : réagir aux clics, aux touches pressées, aux mouvements de la souris… ;
  • Applications web : avec React, Angular et Vue.js, créer des applications complexes ;
  • Programmation côté serveur : avec Node.js, utiliser le même langage côté serveur ;
  • Interfaces utilisateur : bibliothèques et frameworks pour des interfaces élégantes et réactives.
02

Les variables

JavaScript est sensible à la casse : age et Age sont deux variables différentes. Il existe trois façons de déclarer une variable.

📦

Déclarer une variable

Trois mots-clés, trois comportements

var

Déclare une variable, éventuellement initialisée.

  • Portée : fonction (ou globale)
  • Peut être redéclarée
  • Hoisting : élevée à undefined

let

Déclare une variable modifiable, éventuellement initialisée.

  • Portée : bloc courant
  • Ne peut pas être redéclarée
  • Hoisting mais non initialisée

const

Déclare une constante nommée, en lecture seule.

  • Portée : bloc courant
  • Doit être initialisée
  • Recommandée par défaut
Exemple de déclaration : 
var a = 10;
let monVariable = "Bob";
const pi = 3.14;
🎯

Portée et hoisting

Avec var, la variable est globale ou limitée à la fonction où elle est déclarée. Avec let, elle n'existe qu'à l'intérieur du bloc {} où elle est déclarée. 

if (true) {
  var x = 5;
}
console.log(x); // 5 : var ignore la portée du bloc

if (true) {
  let y = 5;
}
console.log(y); // ReferenceError: y is not defined

Les déclarations var sont « élevées » : la variable vaut undefined avant sa déclaration réelle. Les déclarations let sont aussi élevées mais non initialisées : y accéder avant provoque une erreur.

✅

Bonne pratique

En JavaScript moderne, utilisez const par défaut, let quand la valeur doit changer, et évitez var. Vous gardez un meilleur contrôle de la portée et évitez des erreurs courantes.

03

Types de données et littéraux

JavaScript est un langage à typage dynamique : une même variable peut changer de type.

🔢

Les types de données

Les fondamentaux du langage

null Absence volontaire de valeur — let v = null;
undefined Valeur non définie — let v = undefined;
String Texte — let v = "hello";
Number Entier ou décimal — let v = 5;
Boolean true ou false — let v = true;
Array Tableau — let v = ["hello", 5, 10]; (index à 0)
Object Structure regroupant propriétés et méthodes — let v = document.querySelector('h1');
Typage dynamique : 
var message = 42;
message = "hello world"; // aucune erreur

Concaténation et conversions automatiques : avec +, un nombre mélangé à une chaîne est converti en texte. Avec -, c'est la chaîne qui est convertie en nombre. 

x = "La réponse est " + 42; // "La réponse est 42"
y = 42 + " est la réponse"; // "42 est la réponse"

"37" - 7; // 30
"37" + 7; // "377"
🔄

Conversion explicite

// 1er paramètre : la chaîne, 2e paramètre : la base (ici base 2)
parseInt("101", 2); // 5

// Autre méthode : le + unaire devant une chaîne
+"1.1"; // 1.1
📝

Les littéraux

Notations directes de valeurs

Chaînes "Bonjour", 'Bonjour', `Bonjour ${nom}` (gabarit)
Nombres 25 (entier), 19.99 (décimal)
Tableaux ["pomme", "banane", "orange"] — index à 0
Objets { nom: "Doe", prenom: "John", age: 30 }
Expression régulière /[a-zA-Z]+/
Booléens, null, undefined true, false, null, undefined
🔤

Séquences d'échappement

Caractères spéciaux utilisables dans les chaînes :

  • \n — nouvelle ligne ;
  • \t — tabulation ;
  • \" — guillemet double ;
  • \' — apostrophe ;
  • \\ — barre oblique inverse.
04

Les opérateurs

Un opérateur est un symbole qui effectue une opération sur des valeurs (les opérandes) et produit un résultat.

➕

Opérateurs arithmétiques

Calculs de base

+ Addition Ajoute deux valeurs numériques
- Soustraction Soustrait la deuxième valeur de la première
* Multiplication Multiplie deux valeurs
/ Division Divise la première valeur par la deuxième
% Modulo Reste de la division
** Exponentiation Élève la première valeur à la puissance de la deuxième
Exemple : 
let a = 10;
let b = 3;

let addition = a + b;        // 13
let soustraction = a - b;    // 7
let multiplication = a * b;  // 30
let division = a / b;        // 3.333...
let modulo = a % b;          // 1
let exponentiation = a ** b; // 1000
⚖️

Opérateurs de comparaison

Attention aux conversions implicites

== Valeurs égales (sans tenir compte du type)
=== Valeurs égales ET de même type — à privilégier
!= Valeurs différentes (sans tenir compte du type)
!== Valeurs différentes ou de types différents — à privilégier
<, >, <=, >= Comparaison numérique
⚠️

Le piège des conversions

let x = 5;
let y = "5";

console.log(x == y);  // true  (valeurs égales)
console.log(x === y); // false (types différents)
console.log(x != y);  // false (valeurs égales)
console.log(x !== y); // true  (types différents)

Conseil : préférez === et !==, qui évitent les conversions de type implicites.

🔗

Opérateurs logiques

Combiner des conditions

&& ET logique true si les deux opérandes sont true
|| OU logique true si au moins un opérande est true
! NON logique Inverse un booléen
📝

Assignation, incrémentation, ternaire

Opérateurs du quotidien

= Affecte la valeur de droite à la variable de gauche
+= -= *= /= %= **= Effectuent une opération puis assignent le résultat
++ / -- Incrémente / décrémente une variable de 1
? : Ternaire — condition ? valeurSiVraie : valeurSiFausse
+ Concaténation de chaînes
05

Les structures conditionnelles

Les instructions if et else exécutent des blocs de code différents selon une condition booléenne.

🔀

if... else

Structure 1 : un test simple

Syntaxe

if (condition) {
  instruction_1;
} else {
  instruction_2;
}

Exemple : majorité

var age = 18;
if (age >= 18) {
  console.log("Vous êtes majeur.");
}
🎚️

if... else if... else

Structure 2 : plusieurs conditions

Syntaxe

if (condition_1) {
  instruction_1;
} else if (condition_2) {
  instruction_2;
} else {
  derniere_instruction;
}

Exemple : notes

var note = 75;
if (note >= 90) {
  console.log("Très bien !");
} else if (note >= 70) {
  console.log("Bien !");
} else if (note >= 50) {
  console.log("Satisfaisant.");
} else {
  console.log("Insuffisant.");
}
💡

Valeurs évaluées à false

Dans une condition, les valeurs suivantes sont évaluées à false :

  • false
  • undefined
  • null
  • 0
  • NaN
  • "" (chaîne vide)

Toutes les autres valeurs, y compris les objets, sont évaluées à true.

🎛️

switch

Choisir parmi plusieurs valeurs

Syntaxe

switch (choix) {
  case label_1:
    instructions_1;
    break;
  case label_2:
    instructions_2;
    break;
  default:
    instructions_par_defaut;
}

L'instruction break est importante : sans elle, les case suivants s'exécutent aussi.

Exemple : jour de la semaine

var jour = "Lundi";

switch (jour) {
  case "Lundi":
    console.log("Début de la semaine.");
    break;
  case "Vendredi":
    console.log("Presque le week-end !");
    break;
  case "Samedi":
  case "Dimanche":
    console.log("C'est le week-end !");
    break;
  default:
    console.log("Jour non reconnu.");
}

Ici, « Samedi » et « Dimanche » partagent le même bloc : l'absence de break après "Samedi" fait enchaîner volontairement les deux case.

06

Les structures itératives

Une boucle répète un bloc de code. Le choix dépend de ce que l'on connaît à l'avance.

01

for

Nombre connu

À utiliser quand le nombre d'itérations est connu. 

for (initialisation; condition; iteration) {
  // bloc exécuté à chaque itération
}

var nombres = [1, 2, 3, 4, 5];
for (var i = 0; i < nombres.length; i++) {
  console.log(nombres[i]);
}
02

while

Condition vraie

On répète tant qu'une condition est vraie, sans savoir combien de fois. 

while (condition) {
  // bloc exécuté
}

var compteur = 0;
while (compteur < 5) {
  console.log("Itération : " + compteur);
  compteur++;
}
03

do... while

Au moins une fois

Le bloc s'exécute au moins une fois, quelle que soit la condition. 

do {
  // bloc exécuté
} while (condition);

var compteur = 0;
do {
  console.log("Itération : " + compteur);
  compteur++;
} while (compteur < 5);
04

for... of / for... in

Parcourir

for...of parcourt les valeurs ; for...in parcourt les propriétés. 

let arr = [3, 5, 7];
arr.toto = "coucou";

for (let i in arr) {
  console.log(i); // 0, 1, 2, "toto"
}

for (let i of arr) {
  console.log(i); // 3, 5, 7
}
⚠️

Boucle infinie

Avec while, vérifiez que la condition est bien mise à jour dans la boucle pour éviter une boucle infinie.

07

Les fonctions

Une fonction est un bloc de code nommé, réutilisable, qui peut recevoir des paramètres et renvoyer une valeur.

⚙️

Définir une fonction

Syntaxe et variantes

Fonction nommée

function nomDeLaFonction(parametre1, parametre2) {
  // bloc de code à exécuter
}

function direBonjour(nom) {
  console.log("Bonjour, " + nom + " !");
}

Fonction anonyme

var addition = function (a, b) {
  return a + b;
};

console.log(addition(5, 3)); // 8

Récursivité

var factorielle = function fac(n) {
  return n < 2 ? 1 : n * fac(n - 1);
};

console.log(factorielle(3)); // 6
📍

Où déclarer une fonction ?

Une fonction doit se trouver dans la portée où elle est appelée. Elle peut être déclarée après son appel uniquement si elle est définie avec la syntaxe function nomFonction() {}.

Une fonction stockée dans une variable ne peut pas être appelée avant sa déclaration : 

console.log(carre);    // undefined
console.log(carre(5)); // TypeError: carre is not a function
var carre = function (n) {
  return n * n;
};

console.log(carre2);    // ReferenceError
let carre2 = function (n) {
  return n * n;
};

Exécuter du code JavaScript

Il existe deux méthodes principales pour exécuter du code JavaScript.

🌐

Méthode 1 : dans le navigateur

La méthode la plus simple

1. Éditeur de texte Ouvrez Visual Studio Code ou un éditeur similaire.
2. Écrire le code Écrivez votre code JavaScript.
3. Enregistrer Avec l'extension .js (par exemple monscript.js).
4. Ouvrir la console Touche F12 ou Ctrl + Maj + I, onglet Console.
5. Lier le script Avec la balise <script>, ou saisir directement dans la console.
Exemple HTML : 
<!DOCTYPE html>
<html>
  <body>
    <script>
      console.log("Bonjour depuis JavaScript !");
    </script>
  </body>
</html>

Pour lier un fichier externe : <script src="monscript.js"></script>.

🖥️

Méthode 2 : avec Node.js

Côté serveur ou en ligne de commande

1. Installer Node.js Téléchargez sur nodejs.org et installez-le.
2. Écrire le code Dans un éditeur, avec l'extension .js.
3. Ouvrir un terminal Terminal ou invite de commandes.
4. Lancer node nomdufichier.js
09

Les objets en JavaScript

Un objet est une structure de données qui regroupe des propriétés (des variables contenant des données) et des méthodes (des fonctions qui agissent sur l'objet).

01

Date

Dates et heures

Le constructeur Date() sans argument renvoie la date et l'heure actuelles. 

const dateActuelle = new Date();
console.log(dateActuelle);

// À partir d'une chaîne ISO
const d1 = new Date("2023-10-09T11:11:11");

// Année, mois (0-11), jour
const d2 = new Date(2023, 2, 2);

// Année, mois, jour, heures, minutes, secondes
const d3 = new Date(2023, 2, 2, 16, 50, 56);
02

String

Chaînes de caractères

Méthodes utiles pour manipuler du texte. 

const myString = "Hello, world!";

myString.length;              // 13
"Hello".charAt(1);            // "e"
myString.substring(7, 12);    // "world"
"Hello".toUpperCase();        // "HELLO"
"Hello".toLowerCase();        // "hello"
"  Hi  ".trim();              // "Hi"
myString.indexOf("world");    // 7
"apple,banana".split(",");    // ["apple","banana"]
03

Math

Calculs mathématiques

On ne l'instancie pas : on appelle directement Math.méthode(). 

Math.random();             // aléatoire entre 0 et 1
Math.floor(7.85);          // 7
Math.ceil(3.14);           // 4
Math.round(5.6);           // 6
Math.max(10, 5, 20, 15);   // 20
Math.min(10, 5, 20, 15);   // 5
Math.pow(2, 3);            // 8

Astuce — dé à 6 faces : Math.floor(Math.random() * 6) + 1

04

Autres objets

Préconstruits
  • Object — tout objet JavaScript en hérite ;
  • Array — collections ordonnées ;
  • Boolean — valeurs true et false ;
  • document — le DOM de la page web.
📅

Lire et modifier une date

Getters :

  • getFullYear() — l'année
  • getMonth() — le mois (0 à 11)
  • getHours() — l'heure (0 à 23)
  • getMinutes() — les minutes (0 à 59)
  • toLocaleDateString() — date formatée

Setters :

  • setDate(X) — jour du mois
  • setHours(X) — heure
  • setMonth(X) — mois (0 à 11)
10

L'objet document et le DOM

L'objet document représente le Document Object Model (DOM) d'une page web. Il fournit une interface pour interagir avec les éléments HTML.

🔍

Sélectionner des éléments

Les méthodes principales

getElementById Un élément par son id — retourne un élément
getElementsByClassName Les éléments d'une classe — retourne une collection
getElementsByTagName Les éléments d'une balise — retourne une collection
querySelector Le premier élément correspondant à un sélecteur CSS
querySelectorAll Tous les éléments correspondant à un sélecteur CSS
Exemples : 
// Par ID
const paragraph = document.getElementById("my-paragraph");
paragraph.textContent = "Texte modifié.";

// Par classe
const items = document.getElementsByClassName("item");
for (const item of items) {
  item.style.fontWeight = "bold";
}

// Par balise
const paragraphs = document.getElementsByTagName("p");
for (const paragraph of paragraphs) {
  paragraph.style.color = "red";
}

// Par sélecteur CSS
const paragraph = document.querySelector("#container .content");
paragraph.style.backgroundColor = "yellow";

// Tous les éléments correspondants
const listItems = document.querySelectorAll("ul li");
for (const listItem of listItems) {
  listItem.style.listStyleType = "square";
}
🪟

Navigation et interaction avec la fenêtre

  • document.location — URL de la page courante ;
  • window.open — ouvre une nouvelle fenêtre ;
  • window.close — ferme la fenêtre ;
  • window.history — navigue dans l'historique ;
  • window.scrollTo(x, y) — défilement ;
  • window.resizeTo(w, h) — redimensionne.

Sécurité : pour des raisons de sécurité, les navigateurs restreignent certaines de ces actions : resizeTo et close ne fonctionnent que sur des fenêtres ouvertes par le script, et window.open peut être bloqué par un bloqueur de fenêtres publicitaires.
