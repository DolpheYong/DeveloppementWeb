LEÇON CSS

Bases, sélecteurs, DevTools et écoconception

Le CSS donne au HTML son apparence : apprenez à écrire des règles CSS, à cibler les bons éléments, à déboguer avec les DevTools et à styliser de façon sobre et lisible.

Oct 24, 2026 · @Dolphe

🎯

Objectifs

À la fin de cette leçon, l'apprenant sera capable de :

  • expliquer le rôle du CSS par rapport au HTML ;
  • écrire une règle CSS correcte (sélecteur, propriété, valeur) ;
  • choisir entre feuille externe, balise <style> et style en ligne ;
  • cibler des éléments avec les sélecteurs de type, de classe, d'ID, d'attribut et les combinateurs ;
  • utiliser les DevTools du navigateur pour comprendre et corriger un rendu ;
  • appliquer des principes de sobriété (écoconception) à ses choix de style.
01

À quoi sert le CSS ?

Le HTML définit la structure et le sens du contenu (titres, paragraphes, images, liens), mais pas son apparence. Le CSS prend en charge la présentation : c'est l'association des deux qui transforme une simple collection de balises en une page attrayante et ergonomique.

✨

Une page bien stylisée avec CSS est…

  • expressive : elle traduit la personnalité et le style d'une marque ;
  • innovante : elle permet d'expérimenter des designs créatifs ;
  • cohérente : des styles réutilisables garantissent la même apparence sur toutes les pages ;
  • équilibrée : elle maintient un équilibre visuel entre les éléments ;
  • professionnelle : un style soigné renforce la crédibilité du site ;
  • adaptative : la mise en page réactive (responsive) s'ajuste à tous les appareils et tailles d'écran.
02

Le CSS : un langage de style

CSS signifie Cascading Style Sheets, en français « feuilles de style en cascade ». Il applique des règles de style aux éléments HTML grâce à des sélecteurs et des propriétés.

Contrairement à un langage de programmation, le CSS ne prend pas de décisions conditionnelles et n'exécute pas d'instructions logiques : il fournit uniquement des règles pour mettre en forme les éléments.

Structure d'une règle CSS : 
selecteur {
  propriete: valeur;
  autre-propriete: valeur;
}

Une règle se compose de quatre éléments :

  • Le sélecteur désigne les éléments à styliser ;
  • La déclaration est un couple propriété + valeur ;
  • La propriété est la caractéristique visuelle à personnaliser ;
  • La valeur fixe le style précis de la propriété.
📐

Règles de syntaxe à respecter

  • l'ensemble des déclarations d'une règle est placé entre accolades { } ;
  • la propriété est séparée de sa valeur par deux-points : ;
  • les déclarations sont séparées par un point-virgule ;.
03

Où écrit-on le CSS ?

Il existe trois manières d'intégrer du CSS dans un document HTML. Le bon choix dépend de la taille du projet et de la facilité de maintenance recherchée.

📄

a) Feuille de style externe

Recommandée — projets moyens et grands

Principe

Les règles sont écrites une seule fois dans un fichier .css, relié à chaque page avec la balise <link> dans le <head>.

  • Pas de duplication
  • Mise à jour centralisée
  • Apparence identique sur tout le site

Exemple HTML

<!doctype html>
<html>
  <head>
    <meta charset="utf-8" />
    <title>Une expérience avec CSS</title>
    <link rel="stylesheet" href="styles.css" />
  </head>
  <body>
    <h1>Bonjour !</h1>
    <p>Ceci est un premier exemple CSS</p>
  </body>
</html>

Fichier styles.css

h1 {
  color: blue;
  background-color: yellow;
  border: 1px solid black;
}

p {
  color: red;
}
📎

b) Balise <style> dans l'en-tête

Acceptable — petits projets

Principe

Les règles sont écrites directement dans le <head>, entre les balises <style> et </style>. Elles ne s'appliquent qu'à cette page.

Exemple

<head>
  <meta charset="utf-8" />
  <title>Mes expérimentations CSS</title>
  <style>
    h1 {
      color: blue;
      background-color: yellow;
      border: 1px solid black;
    }
    p { color: red; }
  </style>
</head>

⚠️ Inconvénient

Le CSS doit être recopié dans chaque page, et toute mise à jour oblige à modifier chaque fichier. Mieux vaut passer à une feuille externe.

⚠️

c) Styles en ligne

Fortement déconseillé

Principe

Le style est écrit directement dans l'attribut style d'un élément. 

<h1 style="color: blue; background-color: yellow;">
  Bonjour !
</h1>
<p style="color: red;">Mon premier exemple CSS</p>

Pourquoi éviter ?

  • Les modifications touchent chaque élément de chaque page ;
  • Mélange du CSS avec le HTML, nuisible à la lisibilité ;
  • Difficile à maintenir en équipe ;
  • Sépare mal le contenu de la mise en forme.
04

Les sélecteurs CSS

Toute règle CSS commence par un sélecteur : une expression qui indique au navigateur à quels éléments HTML la règle s'applique. Les éléments ciblés en sont le sujet.

01

Sélecteurs simples

Débutant

Ciblent les éléments selon leur nom, leur identifiant ou leur classe.

  • Sélecteur de type : em, strong
  • Sélecteur de classe : .highlight
  • Sélecteur d'ID : #one
  • Sélecteur universel : *
02

Combinateurs

Débutant

Ciblent les éléments selon leur relation avec d'autres éléments.

  • Descendant : div p
  • Enfant direct : div > p
  • Frère immédiat : h2 + p
  • Frère général : h2 ~ p
03

Sélecteurs d'attributs

Débutant

Ciblent les éléments selon la présence ou la valeur d'un attribut.

  • li[class] — présence de l'attribut
  • li[class="a"] — valeur exacte
  • li[class^="a"] — commence par
  • li[class$="a"] — se termine par
  • li[class*="a"] — contient
04

Pseudo-classes & pseudo-éléments

Intermédiaire

Ciblent un état ou une partie d'un élément.

  • État : :hover, :focus, :visited
  • Structure : :first-child, :nth-child()
  • Éléments : ::before, ::after
Cascade et spécificité :

À sélecteurs équivalents, la déclaration qui apparaît en dernier dans la feuille de style remplace les précédentes. Plus un sélecteur est précis, plus sa priorité est forte ; à précision égale, la dernière règle gagne. 

p { color: red; }
p { color: blue; }       /* Le paragraphe est bleu */

.special { color: red; }
p { color: blue; }       /* Un <p class="special"> est rouge */
⚠️

Groupement de sélecteurs

Quand plusieurs éléments partagent les mêmes déclarations, on regroupe les sélecteurs en les séparant par une virgule. 

h1,
.special {
  color: blue;
}

Attention : si un seul sélecteur du groupe est invalide, toute la règle est ignorée.

05

Liste des principales propriétés

Propriété : color

  • Explication : Définit la couleur du texte.
  • Valeurs possibles : noms de couleur (red, blue), codes hexadécimaux (#FF0000), codes RGB (rgb(255, 0, 0)).
  • Exemple : color: blue;

Propriété : font-size

  • Explication : Contrôle la taille de la police.
  • Valeurs possibles : pixels (12px), em (1.5em), pourcentage (150%).
  • Exemple : font-size: 16px;

Propriété : text-align

  • Explication : Aligne le texte dans un élément.
  • Valeurs possibles : left, right, center, justify.
  • Exemple : text-align: center;

Propriété : background-color

  • Explication : Définit la couleur de l'arrière-plan.
  • Valeurs possibles : mêmes valeurs que pour la propriété color.
  • Exemple : background-color: #F0F0F0;

Propriété : border

  • Explication : Crée une bordure autour de l'élément.
  • Valeurs possibles : taille (1px), style (solid, dotted), couleur (valeurs de couleur).
  • Exemple : border: 1px solid black;

Propriété : margin

  • Explication : Espace entre l'élément et les éléments voisins.
  • Valeurs possibles : pixels, pourcentage, auto.
  • Exemple : margin: 10px;

Propriété : padding

  • Explication : Espace entre le contenu de l'élément et sa bordure.
  • Valeurs possibles : pixels, pourcentage.
  • Exemple : padding: 20px;

Propriété : display

  • Explication : Contrôle le comportement d'affichage de l'élément.
  • Valeurs possibles : block, inline, inline-block, flex, grid, etc.
  • Exemple : display: inline-block;

Propriété : position

  • Explication : Contrôle le positionnement de l'élément.
  • Valeurs possibles : static, relative, absolute, fixed.
  • Exemple : position: absolute;

Propriété : width

  • Explication : Définit la largeur de l'élément.
  • Valeurs possibles : pixels, pourcentage, auto.
  • Exemple : width: 300px;

Propriété : font-family

  • Explication : Spécifie la police à utiliser pour le texte.
  • Valeurs possibles : Noms de polices, familles génériques (serif, sans-serif, monospace, etc.).
  • Exemple : font-family: "Arial", sans-serif;

Propriété : line-height

  • Explication : Contrôle l'espacement vertical entre les lignes de texte.
  • Valeurs possibles : Valeurs numériques, valeurs sans unités, pourcentages.
  • Exemple : line-height: 1.5;

Propriété : font-weight

  • Explication : Définit l'épaisseur de la police (gras ou normal).
  • Valeurs possibles : normal, bold, bolder, lighter, valeurs numériques.
  • Exemple : font-weight: bold;

Propriété : text-decoration

  • Explication : Ajoute ou supprime la décoration du texte, comme les soulignements.
  • Valeurs possibles : none, underline, overline, line-through, initial.
  • Exemple : text-decoration: underline;

Propriété : border-radius

  • Explication : Définit le rayon des coins arrondis d'un élément avec une bordure.
  • Valeurs possibles : Valeurs numériques (px, em, %), valeurs multiples pour les coins individuels.
  • Exemple : border-radius: 10px;

Propriété : box-shadow

  • Explication : Ajoute une ombre à un élément.
  • Valeurs possibles : Position de l'ombre, décalage horizontal, décalage vertical, flou, couleur.
  • Exemple : box-shadow: 2px 2px 4px rgba(0, 0, 0, 0.2);

Propriété : text-transform

  • Explication : Modifie la casse du texte (majuscules, minuscules, etc.).
  • Valeurs possibles : uppercase, lowercase, capitalize, none.
  • Exemple : text-transform: uppercase;

Propriété : position

  • Explication : Définit la méthode de positionnement d'un élément.
  • Valeurs possibles : static, relative, absolute, fixed, sticky.
  • Exemple : position: absolute;

Propriété : z-index

  • Explication : Contrôle l'empilement d'éléments positionnés.
  • Valeurs possibles : Valeurs numériques, auto.
  • Exemple : z-index: 1;

Propriété : opacity

  • Explication : Contrôle le degré de transparence d'un élément.
06

Les DevTools : observer et corriger

Lorsque l’on apprend à utiliser CSS3 pour styliser une page web, on se concentre généralement sur les propriétés de base : couleurs, marges, polices, bordures, alignements, tailles, affichage en colonnes, responsive design, etc.
Mais dans la pratique professionnelle, écrire des règles CSS ne suffit pas. Il faut aussi apprendre à :

  1. observer et corriger le rendu réel dans le navigateur,
  2. faire des choix de style responsables, lisibles et performants.

C’est dans cette logique que s’inscrivent les deux sections suivantes :

  • Utiliser les outils de développement du navigateur (DevTools) ;
  • Appliquer des principes d’écoconception côté CSS.

 

🛠️

Pourquoi les DevTools sont indispensables

On rencontre vite des situations déroutantes : une couleur qui ne s'applique pas, un bloc qui n'a pas la bonne largeur, une marge « incompréhensible »… L'erreur fréquente est de modifier le CSS au hasard.

Les DevTools permettent de :

  • voir exactement quel élément HTML est concerné ;
  • observer les règles CSS réellement appliquées ;
  • repérer les propriétés ignorées ou écrasées ;
  • tester une modification immédiatement ;
  • vérifier le comportement responsive ;
  • analyser la structure de la mise en page.
Comment les ouvrir ?
  • clic droit sur un élément, puis Inspecter ;
  • touche F12 ;
  • raccourci Ctrl + Maj + I.
01

Éléments

Structure HTML

Affiche la structure HTML de la page et la place de chaque élément dans la hiérarchie.

  • Pourquoi ce bloc n'est-il pas là où je l'attends ?
  • Ai-je utilisé la bonne classe ?
  • L'élément est-il dans le bon conteneur ?
02

Styles

Règles appliquées

Affiche les propriétés appliquées à l'élément sélectionné, les règles héritées et les propriétés barrées (non utilisées).

  • Quelle règle l'emporte ?
  • Une règle plus spécifique écrase-t-elle la mienne ?
  • Mon sélecteur est-il le bon ?
03

Computed

Valeurs finales

Affiche les valeurs finales retenues par le navigateur : taille réelle du texte, largeur finale, marges calculées, couleur finale.

  • Quel est le résultat concret après toutes les règles ?
04

Modèle de boîte

Box Model

Représente chaque élément comme une boîte : contenu, padding, bordure, marge.

  • Pourquoi ce bloc prend-il trop de place ?
  • Pourquoi cet espacement est-il plus grand que prévu ?
🔄

La méthode à acquérir (5 étapes)

  1. Identifier l'élément concerné avant de corriger.
  2. Observer les styles appliqués : quelles règles s'appliquent, lesquelles sont barrées.
  3. Tester une correction directement dans le navigateur.
  4. Vérifier le résultat, sur plusieurs tailles d'écran si nécessaire.
  5. Reporter la correction dans le fichier source.

Point essentiel : les modifications faites dans les DevTools sont temporaires. Elles disparaissent au rechargement de la page.

07

L'écoconception côté CSS

Quand on découvre le CSS, on a souvent envie de « faire plus » : plus de couleurs, de polices, d'effets, d'ombres, d'animations. Mais en conception web, plus ne signifie pas mieux : une page chargée peut être fatigante à lire, moins claire et plus difficile à maintenir.

🌱

Une sobriété intelligente, pas un site austère

Écoconcevoir ne signifie pas faire un site « sans style », triste ou sans identité visuelle. Il s'agit de styliser avec intention, de chercher l'efficacité visuelle, d'éviter la surcharge et de garder une interface simple à lire. Le CSS devient un outil de mise en forme utile, et non un simple moyen d'ajouter des effets.

🎨

La sobriété visuelle : quatre principes

Des choix graphiques raisonnés

1. Limiter le nombre de couleurs Une couleur principale, une ou deux secondaires, quelques gris, éventuellement une couleur d'accent.
2. Limiter le nombre de polices Une police principale, éventuellement une seconde pour les titres. Au-delà, l'interface devient vite désordonnée.
3. Espacer de façon cohérente Marges, padding, distances régulières : une interface bien espacée est plus claire et plus facile à lire.
4. Réduire les effets décoratifs inutiles Ombres, dégradés, animations et arrondis restent possibles, mais mesurés. Cet effet améliore-t-il vraiment l'interface, ou ajoute-t-il du bruit visuel ?
⚡

La performance côté CSS

Simplicité et efficacité

Éviter les styles inutiles Une règle sans utilité claire n'a peut-être pas besoin d'exister.
Éviter la répétition excessive Un CSS bien organisé est plus facile à maintenir.
Ne pas surcharger visuellement la page Une page trop chargée est plus difficile à lire et à utiliser.
Limiter les animations complexes Elles doivent rester utiles et raisonnables.
Faire des choix graphiques mesurés Un design simple est souvent plus lisible, plus élégant, plus durable et plus facile à corriger.
Exemples de décisions plus responsables :
  • Couleurs : 6 ou 7 couleurs différentes → une palette simple et cohérente ;
  • Typographie : multiplication des effets → des tailles cohérentes qui créent une hiérarchie claire ;
  • Bouton : plusieurs ombres, dégradés et animations → une bonne couleur, un contraste suffisant et un padding adapté ;
  • Sections : blocs denses et chargés → blocs courts, bien espacés, peu de surcharge visuelle.
✏️

Exercices

Trois exercices pour mettre en pratique les notions de cette leçon.

01

Le sélecteur descendant

Sélecteurs

Le code ci-dessous contient seulement deux règles. Ajoutez une règle qui applique la couleur rouge aux <span> uniquement lorsqu'ils sont contenus dans un élément <p>. 

li em {
  color: red;
}

h1 + p {
  font-size: 200%;
}

Résultat attendu : le <span> du premier paragraphe devient rouge, tandis que celui de la liste reste inchangé.

02

Diagnostiquer avec les DevTools

DevTools
  1. Ouvrez une de vos pages et faites un clic droit sur un titre, puis Inspecter.
  2. Dans le panneau Styles, repérez une propriété barrée et expliquez pourquoi elle est ignorée.
  3. Testez une nouvelle marge directement dans le navigateur.
  4. Passez en mode responsive et vérifiez l'affichage sur mobile.
  5. Reportez votre correction dans le fichier CSS.
03

Alléger une page

Écoconception

Reprenez l'une de vos pages et réduisez-la à une palette de trois couleurs et une ou deux polices. Notez, pour chaque effet supprimé, pourquoi il n'apportait rien.

✓

À retenir

Le HTML structure, le CSS présente. Un bon style est sobre, cohérent et justifié : chaque choix répond à une intention.
