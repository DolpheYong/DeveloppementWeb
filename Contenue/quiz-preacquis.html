1

Qu'est-ce que Git ?

💡 Explication Git est un logiciel de gestion de versions décentralisé qui fonctionne sur votre ordinateur, sans connexion Internet. GitHub, c'est le service en ligne qui héberge des dépôts Git.
2

Quelle est la différence principale entre Git et GitHub ?

💡 Explication Git fonctionne en local sur votre ordinateur. GitHub est le service cloud qui héberge vos dépôts Git en ligne. Git fonctionne sans GitHub, mais GitHub a besoin de Git.
3

Quelle commande prépare un fichier avant un commit ?

💡 Explication git add place les modifications dans la "zone de préparation" (staging area). git commit enregistre ensuite la version, et git push l'envoie sur GitHub.
4

Que fait la commande git commit -m "Mon message" ?

💡 Explication git commit prend une "photo" de votre projet à un instant donné. Le message (-m) décrit ce qui a changé. Le commit est local : il faut ensuite git push pour l'envoyer sur GitHub.
5

Quelle commande permet d'envoyer ses commits sur GitHub ?

💡 Explication git push envoie les commits locaux vers le dépôt distant (GitHub). git pull fait l'inverse : il récupère les modifications distantes.
6

Quel nom de fichier est obligatoire pour la page d'accueil d'un site GitHub Pages ?

💡 Explication GitHub Pages (comme la plupart des serveurs web) cherche automatiquement un fichier index.html à la racine du dépôt. C'est la cause n°1 des erreurs 404 sur GitHub Pages.
7

Où configure-t-on GitHub Pages dans un dépôt ?

💡 Explication Le chemin est : Settings → Pages → Source : Deploy from a branch → main → / (root) → Save. L'URL publique apparaît ensuite après 1 à 10 minutes.
8

Que fait l'extension Live Server de VS Code ?

💡 Explication Live Server crée un petit serveur web local (typiquement sur http://127.0.0.1:5500) et recharge automatiquement la page dans le navigateur à chaque Ctrl+S. Très pratique pour voir ses modifications en direct.
9

Quel terminal faut-il privilégier sous Windows pour suivre les tutoriels Git ?

💡 Explication Git Bash est fourni avec Git for Windows et utilise les mêmes commandes que les tutoriels en ligne (Linux / macOS). C'est plus proche des exemples que vous trouverez sur le web.
10

Quel est le cycle de travail typique avec Git ?

💡 Explication Le cycle est toujours : modifier → git add → git commit -m "message" → git push. L'ordre est important : on prépare, on enregistre localement, puis on envoie en ligne.
