Initiation au HTML

Comprendre les bases du langage HTML, créer une page web structurée, utiliser les balises et attributs, gérer les liens, les images et les tableaux.

1. Introduction

HTML, acronyme de HyperText Markup Language (Langage de Balisage Hypertexte), est la base de tout site web. Il s'agit d'un langage de balisage et non d'un langage de programmation.

À retenir : HTML définit principalement la structure et le contenu d'une page web grâce à des balises.

Les balises permettent notamment d'identifier un paragraphe, une liste, un titre, un lien, une image, un formulaire ou encore un contenu multimédia. Elles permettent également de donner une structure sémantique au document, ce qui facilite notamment l'accessibilité et l'indexation.

HTML Structure et contenu de la page.
CSS Présentation, couleurs, polices, marges et mise en forme.
JavaScript Interactivité et comportement dynamique.

L'association de HTML et CSS repose notamment sur la séparation du contenu et de la présentation. JavaScript peut ensuite être associé à HTML pour ajouter de l'interactivité.

Pour écrire du HTML, CSS et JavaScript, différents éditeurs de texte peuvent être utilisés, notamment Visual Studio Code (VS Code), Notepad++, Sublime Text ou Atom.

2. Les balises

Une balise est une suite de caractères écrite entre les chevrons < et >. Elle indique au navigateur la nature du contenu qu'elle englobe.

La casse des éléments HTML n'a pas d'incidence, mais il est recommandé d'utiliser les minuscules pour conserver une bonne cohérence.

Balises en paire

Elles possèdent une balise ouvrante et une balise fermante. 

<p>Mon premier paragraphe</p>

Ici, <p> ouvre le paragraphe et </p> le ferme.

Balises orphelines

Elles ne possèdent pas de contenu à englober et ne nécessitent pas de balise fermante. 

<img src="banniere.png">
En HTML moderne, on écrit généralement <img> plutôt que <img/>.

3. Les attributs

Les attributs fournissent des informations supplémentaires concernant un élément. Ils sont généralement placés dans la balise ouvrante. 

<p id="section2">Madagascar est un pays africain.</p>

Pour écrire un attribut :

  1. Insérer un espace entre le nom de l'élément et l'attribut.
  2. Écrire le nom de l'attribut.
  3. Ajouter le signe =.
  4. Placer sa valeur entre guillemets.

Exemple avec un lien

<a href="https://www.auf.org/"
   title="Page d'accueil de l'AUF"
   target="_blank">
  Site Web de l'Agence universitaire de la Francophonie
</a>
Attribut Rôle
href Indique l'adresse vers laquelle le lien dirige.
title Fournit une information supplémentaire.
target Détermine le contexte de navigation, par exemple un nouvel onglet avec _blank.

Attributs booléens

Certains attributs fonctionnent sans valeur explicite. 

<input type="text" disabled>

La forme disabled="disabled" est également possible, mais la forme courte est couramment utilisée.

Les guillemets

Les valeurs d'attributs peuvent être écrites avec des guillemets doubles ou simples. 

<a href="http://www.exemple.com">Mon exemple</a>

<a href='http://www.exemple.com'>Mon exemple</a>

4. Premiers pas dans le code

  1. Préparer l'environnement : ouvrir un éditeur de texte pour écrire le code.
  2. Créer le fichier : utiliser l'extension .html, par exemple mon-premier-exemple.html.
  3. Écrire le code : ajouter les balises nécessaires à la structure de la page.
  4. Visualiser : ouvrir le fichier HTML dans un navigateur.

5. Structure d'un document HTML

Une page HTML possède une structure générale permettant de séparer les informations destinées au navigateur du contenu visible par l'utilisateur. 

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Ma page</title>
</head>
<body>
  <h1>Bienvenue</h1>
  <p>Ma première page HTML.</p>
</body>
</html>
Structure essentielle : <html> contient le document, <head> contient les informations de configuration et <body> contient le contenu affiché.

6. Commentaires

Les commentaires permettent d'ajouter des annotations dans le code. Ils sont ignorés par le navigateur et ne sont pas affichés comme contenu de la page. 

<!-- Ceci est un commentaire HTML -->

Ils peuvent servir à expliquer le fonctionnement du code ou à identifier les différentes parties d'un document.

7. L'en-tête <head>

L'élément <head> contient des informations qui ne sont généralement pas affichées directement dans la page.

Il peut notamment contenir :

  • le titre de la page avec <title> ;
  • des liens vers des feuilles de style CSS ;
  • des balises <meta> ;
  • des liens vers d'autres ressources.
<head>
  <!-- Auteur de la page -->
  <meta name="author" content="D-CLIC">

  <title>Ma page de test</title>

  <!-- Feuille de style CSS -->
  <link rel="stylesheet" href="styles.css">
</head>

8. La balise <meta>

Les balises <meta> définissent des métadonnées, c'est-à-dire des informations destinées notamment au navigateur et aux moteurs de recherche.

Exemple Utilisation
charset="utf-8" Définit l'encodage des caractères.
name="description" Définit une description de la page.
name="author" Indique l'auteur.
name="viewport" Configure l'affichage adapté aux appareils mobiles.
http-equiv="refresh" Permet notamment de définir un rafraîchissement automatique. 
<meta name="description" content="Initiation en HTML">
<meta name="author" content="D-CLIC">
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

9. Les hyperliens

Les hyperliens permettent de relier un document à un autre document, une autre page ou une autre ressource.

Anatomie d'un lien

<p>
  Je visite
  <a href="https://www.auf.org">
    la page d'accueil de l'AUF
  </a>.
</p>

Ajouter un titre au lien

<a
  href="https://www.auf.org"
  title="Les évènements et actualités de l'AUF">
  Page d'accueil de l'AUF
</a>

Transformer une image en lien

<a href="https://www.auf.org">
  <img src="auf.png" alt="Logo AUF">
</a>

10. Liens hypertextes et chemins d'accès

Même dossier href="page2.html"
Dossier parent href="../page2.html"
Sous-dossier href="contenu/page2.html"

Le navigateur utilise la position du fichier courant pour interpréter un chemin relatif.

11. Les liens vers une ancre

Une ancre permet de créer un point de repère à l'intérieur d'une page. L'attribut id doit être unique dans la page. 

<h2 id="section1">Section 1</h2>

<a href="#section1">
  Aller à la Section 1
</a>

Ancre située dans une autre page

<a href="page2.html#section2">
  Aller à la Section 2 de la Page 2
</a>

12. Liens vers des ressources non-HTML

Lorsqu'un lien mène vers un PDF, une vidéo, un fichier ou une autre ressource, il est utile d'indiquer clairement la nature de la ressource. 

<a href="documents/rapport.pdf">
  Télécharger le rapport (PDF)
</a>

<a href="https://www.youtube.com/" target="_blank">
  Regarder la vidéo
</a>

Attribut download

L'attribut download permet d'indiquer qu'une ressource est destinée au téléchargement. 

<a href="fichier.pdf" download>
  Télécharger le document
</a>

13. Liens de courriel

Le schéma mailto: permet de créer un lien qui ouvre le logiciel de messagerie de l'utilisateur. 

<a href="mailto:formation@auf.org">
  Envoyer un courriel
</a>

Il est également possible de fournir un sujet, une copie et un corps de message. 

<a href="mailto:formation@auf.org?subject=FormationHTML&body=Bonjour">
  Envoyer un e-mail
</a>

14. URL absolue et URL relative

URL absolue Contient l'adresse complète, par exemple : https://www.exemple.com/projets/index.html
URL relative Dépend de la position du fichier courant, par exemple : documents/fichier.pdf
Pour les ressources internes d'un même site, les chemins relatifs sont généralement pratiques car ils permettent de conserver une structure indépendante du domaine.

15. Les images en HTML

L'élément <img> permet d'insérer une image dans une page HTML. 

<img src="chemin-vers-image.jpg"
     alt="Description de l'image">

Chemin d'accès

<img src="francophonie.png" alt="Logo">

<img src="images/francophonie.png" alt="Logo">

Texte alternatif

L'attribut alt fournit une description textuelle de l'image. Il est important pour l'accessibilité. 

<img
  src="images/francophonie.jpg"
  alt="Logo officiel de l'Organisation Internationale de la Francophonie">

Dimensions et titre

<img
  src="images/francophonie.png"
  alt="Logo de la Francophonie"
  width="600"
  height="300"
  title="La Francophonie">

Figure et légende

<figure>
  <img
    src="images/francophonie.png"
    alt="Logo officiel de l'Organisation Internationale de la Francophonie">
  <figcaption>La Francophonie</figcaption>
</figure>
À retenir : <figure> peut contenir une image, mais également d'autres contenus comme du code, des tableaux ou des médias.

16. Les tableaux en HTML

Les tableaux permettent de présenter des informations organisées en lignes et en colonnes, par exemple un emploi du temps ou des données financières.

Premier tableau

<table>
  <tr>
    <td>Première cellule</td>
    <td>Deuxième cellule</td>
    <td>Troisième cellule</td>
  </tr>
</table>

Ajouter plusieurs lignes

<table>
  <tr>
    <td>Cellule 1</td>
    <td>Cellule 2</td>
    <td>Cellule 3</td>
  </tr>

  <tr>
    <td>Cellule 4</td>
    <td>Cellule 5</td>
    <td>Cellule 6</td>
  </tr>
</table>

Ajouter des en-têtes avec <th>

<table>
  <tr>
    <th>Spécialité</th>
    <th>Nom du cours</th>
    <th>Nombre d'apprenants</th>
  </tr>

  <tr>
    <td>Informatique</td>
    <td>Python</td>
    <td>22</td>
  </tr>
</table>

Exemple complet

Spécialité Nom du cours Nombre d'apprenants
Informatique Python 22
Informatique Java 112
Électrique Système logique 27
Biologie Génétique 13

17. Structuration et fusion des tableaux

Fusion de lignes avec rowspan

rowspan permet à une cellule de s'étendre sur plusieurs lignes. 

<table>
  <tr>
    <td rowspan="2">Cellule fusionnée</td>
    <td>Ligne 1, Colonne 2</td>
  </tr>

  <tr>
    <td>Ligne 2, Colonne 2</td>
  </tr>
</table>

Fusion de colonnes avec colspan

colspan permet à une cellule de couvrir plusieurs colonnes. 

<table>
  <tr>
    <td>Colonne 1</td>
    <td colspan="3">Cellule fusionnée sur trois colonnes</td>
  </tr>
</table>

Utiliser <thead> et <tbody>

Ces éléments permettent de séparer l'en-tête du contenu principal du tableau. 

<table>
  <thead>
    <tr>
      <th>Référence</th>
      <th>Nom</th>
      <th>Disponibilité</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>A1-521</td>
      <td>Produit A1</td>
      <td>Oui</td>
    </tr>

    <tr>
      <td>A2-224</td>
      <td>Produit A2</td>
      <td>Non</td>
    </tr>
  </tbody>
</table>
Résumé : les balises <table>, <tr>, <th> et <td> constituent les éléments fondamentaux des tableaux. Les éléments <thead> et <tbody> permettent d'organiser leur structure.

À retenir

HTML Structure le contenu d'une page.
Balises Définissent la nature des éléments.
Attributs Ajoutent des informations aux éléments.
Liens Utilisent principalement <a> et href.
Images Utilisent <img> et l'attribut alt.
Tableaux Utilisent <table>, <tr>, <th> et <td>.
