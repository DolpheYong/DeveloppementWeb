Qui suis-je ?

Étudiant en informatique à l'Université de Toamasina, je suis titulaire d'une Licence en Informatique, spécialité Développement Web et Mobile. Passionné par le code et la transmission, j'accompagne les débutants complets dans leurs premiers pas en développement web.

Objectifs

Ce que vous allez apprendre

À la fin de cette formation, vous serez capable de :

✓

Comprendre le web

Saisir le fonctionnement du web et la structure d'une page HTML.

✓

Structurer une page

Utiliser les balises HTML sémantiques pour organiser votre contenu.

✓

Styliser avec CSS

Maîtriser les couleurs, la typographie et les mises en page modernes.

✓

Créer du responsive

Concevoir des designs adaptés au mobile, à la tablette et au desktop.

✓

Ajouter de l'interactivité

Utiliser JavaScript pour rendre vos pages vivantes et réactives.

✓

Réaliser un mini-projet

Mettre en pratique toutes les notions dans un projet complet en autonomie.
